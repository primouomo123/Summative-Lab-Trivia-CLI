# Summative-Lab-Trivia-CLI

Inside the Summative-Lab-Trivia-CLI folder you can eaither:
1. run **node bin/index.js** to run the game

2. Make the CLI executable and link it globally by running:
$ chmod +x bin/index.js
$ npm link
AFter the 2 previous commands were run, you can just run **Summative-Lab-Trivia-CLI** to run the trivia game.
